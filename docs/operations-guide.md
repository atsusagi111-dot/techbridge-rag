# 社内文書アシスタント 運用手順書（クライアント向け）

対象システム: テックブリッジ 社内文書アシスタント
最終更新: 2026-08-30

このドキュメントは、社内文書アシスタントを日常的にご利用いただく方向けの操作マニュアルです。システムの内部構成については [`architecture.md`](./architecture.md)（情シス向け）をご参照ください。

## 1. このツールでできること

就業規則・経費精算・情報セキュリティ規程などの社内文書について、Web画面またはSlackで質問すると、**文書に書かれている内容だけを根拠に**回答します。回答には必ず「どの文書の何ページに書かれているか」が表示され、その場でPDFの該当ページを開いて原文を確認できます。

> ⚠️ 現時点で本ツールが参照しているのは以下5種類のサンプル文書のみです。それ以外の社内規程については回答できません（§5「制限事項」を参照）。
> - 就業規則
> - 経費精算マニュアル
> - 情報セキュリティ規程
> - リモートワーク規程
> - 社内ITツールガイド

## 2. Web版の使い方

1. ブラウザで下記URLを開きます。
   **https://techbridge-rag.vercel.app**
2. 中央のテキスト欄に質問を日本語で入力します。
   例:「有給休暇は入社から何ヶ月で何日付与されますか？」
3. 「質問する」ボタンを押します（通常5秒前後で回答が表示されます）。
4. 回答の下に表示される丸みのあるバッジ（例: `就業規則.pdf p.1`）が出典です。**クリックすると該当PDFの該当ページが新しいタブで開きます。** 必ず一度、原文を確認してから業務判断にお使いください。

### 良い質問の仕方

- 一つの質問につき一つの論点にする（例: 「有給と経費精算について教えて」ではなく、2回に分けて質問する）
- 固有名詞・数値を尋ねる質問（「何日？」「いくら？」「何時から？」）が最も精度高く回答されます
- 曖昧な質問（「休みについて教えて」等）よりも具体的な質問の方が、より的確な出典とともに回答されます

## 3. Slack版の使い方

1. Slackワークスペース内で、質問したいチャンネル（またはDM）から `@RAGtest` にメンションし、続けて質問内容を書きます。
   例: `@RAGtest 情報漏えいに気づいたら何分以内に報告すべきですか？`
2. Botがスレッド内で回答します（出典はテキストの末尾に `（出典: 就業規則.pdf p.1）` の形式で記載されます）。
3. Web版と異なり、Slack上の出典はテキストのみで、クリックしてPDFを開く機能はありません。PDFの原文を確認したい場合はWeb版（https://techbridge-rag.vercel.app）で同じ質問をしてください。

## 4.「該当なし」と表示されたときは

文書に記載のない内容を質問すると、憶測で答えることはせず、必ず **「該当なし」** とだけ回答します。これは不具合ではなく、誤った情報を答えないための仕様です。

「該当なし」と表示された場合は、以下をご確認ください。

- 質問がそもそも本ツールの対象文書（就業規則・経費精算・情報セキュリティ規程・リモートワーク規程・社内ITツールガイド）の範囲内か
- 言い回しを変えて質問し直す（同じ内容でも表現によって検索精度が変わることがあります）
- それでも該当なしの場合は、担当部署（人事部・経理部・情報システム部など）に直接お問い合わせください

## 5. 制限事項・注意事項

- **アクセス制限なし**: 現在このツールのURLは、社内メールアドレスなどによるログイン制限を設けていません。URLを知っている人であれば誰でも質問・PDF閲覧が可能です。社外秘情報の取り扱いに関する社内ルールに従い、URLの外部共有は行わないでください。
- **対象文書は5種類のみ**: 上記5文書以外の内容（例: 育児休業、給与規程の詳細など）は「該当なし」と返され、実際に規程が存在しないという意味ではありません。
- **回答は必ず原文で裏取りする**: LLM（生成AI）による要約のため、まれに文言のニュアンスが原文と異なる場合があります。重要な判断（懲戒・法務・金額が絡む申請など）の前には、必ず出典バッジからPDF原文を確認してください。
- **応答時間**: 通常3〜5秒程度ですが、アクセスが集中した場合やAI側の混雑状況によりこれより時間がかかることがあります。

## 6. お問い合わせ・障害報告

| 内容 | 連絡先 |
| --- | --- |
| 回答内容に誤りがある / 文書の追加・更新を依頼したい | 情報システム部（担当者未設定 — 別途ご記入ください） |
| ツールが動作しない・エラーが出る | 開発担当（別途ご記入ください） |
| Slack Botが反応しない | Slackワークスペースの `#it-helpdesk` |

## 7. 用語集

| 用語 | 説明 |
| --- | --- |
| 出典バッジ | 回答の下に表示される「文書名 p.ページ番号」のラベル。クリックでPDFの該当ページに直接ジャンプします。 |
| 該当なし | 質問に対応する記載が対象文書内に見つからなかった場合の回答。 |
| RAG（検索拡張生成） | 生成AIが自由に答えるのではなく、社内文書から関連箇所を検索し、その内容だけを根拠に回答する仕組み。 |
