# 社内ITツール・アカウント申請ガイド

**株式会社テックブリッジ／改定日: 2025年11月1日／管轄: 情報システム部**

> 本書は RAG 検索 AI（案件3）の取り込み用サンプル社内文書です。実在の規程ではありません。

## 1. 入社時に付与されるアカウント

入社初日に、情報システム部から以下のアカウントを付与する。

- Google Workspace（メール・カレンダー・ドライブ）
- Slack（社内コミュニケーション）
- 1Password（パスワード管理）
- GitHub（開発部のみ）

## 2. 申請窓口

- アカウント・ツールに関する申請・相談は、Slack の **#it-helpdesk** で受け付ける。
- チャットで対応できない場合は it@techbridge.co.jp へメールする。

## 3. 主なツールと利用範囲

| ツール | 用途 | 利用範囲 |
| --- | --- | --- |
| Slack | 社内連絡 | 全社員 |
| Notion | ドキュメント・議事録 | 全社員 |
| Figma | デザイン作成 | デザイン部・開発部 |
| AWS | 開発・インフラ | 開発部のみ |
| マネーフォワード | 経費精算 | 全社員 |

## 4. アカウント申請の流れ

1. 利用したいツールを #it-helpdesk に申請する。
2. 上長が Slack 上で承認する。
3. 情報システム部が2営業日以内にアカウントを発行する。

## 5. 退社時の手続き

- 貸与された PC・周辺機器は最終出社日までに情報システム部へ返却する。
- 各種アカウントは、情報セキュリティ規程に基づき最終出社日の翌営業日までに無効化する。

## 6. PC・ネットワークのトラブル

- PC が起動しない、ネットワークに繋がらない等のトラブルは #it-helpdesk へ。
- 緊急時（全社的な障害）は、情報システム部の内線または security@techbridge.co.jp へ連絡する。
